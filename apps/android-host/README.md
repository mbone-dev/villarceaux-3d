# android-host

Intégration future prévue : WebView Android chargeant le build statique exporté du module web.

- Aucun test Android réel n'a été exécuté dans ce dépôt pour cette V1.
- Cette V1 ne promet pas de compatibilité matérielle spécifique sans validation tablette.
- API d'intégration visée : `mount`, `setView`, `startTour`, `stopTour`, `setQuality`, `dispose`.
